# 关卡表导入说明

项目保留两份独立的 Excel 源表，不需要合并：

- `model.xlsx`：角色、Buff、怪物等基础数值。
- `关卡source_两路_教学12实战3.xlsx`：关卡时间轴和左右路摆放。

## 导入基础数值

1. 在 Unity 中打开 `Tools > Demo > Import Model Table`。
2. 选择 `model.xlsx`。
3. 导入结果写入 `Assets/Resources/Config/model_config.json`。

## 导入关卡

1. 在 Unity 中打开 `Tools > Demo > Import Level Table`。
2. 选择关卡源表。
3. 导入结果写入 `Assets/Resources/Config/level_config.json`。
4. 进入 Play Mode。游戏启动时会优先读取导入的关卡；文件不存在、为空或格式无效时，才使用代码中的内置关卡。

关卡源表必须包含名为 `source` 的工作表，以及 `关卡`、`左`、`右`、`秒` 四列。关卡编号只需在一关的首行填写，后续空白行会自动沿用该编号。`秒` 可以填写单个时间点（如 `3`）或区间（如 `3-5`）；区间使用起始时间 `3`。

## 词条映射

| Excel 词条 | 游戏事件 | 说明 |
| --- | --- | --- |
| `鸡N` | 普通鸡群 | `N` 是数量，如 `鸡6` |
| `肥鸡` | 肥鸡 | 数量固定为 1 |
| `快鸡` | 快鸡 | 数量固定为 1 |
| `鸡boss` | Boss 鸡 | 数量固定为 1 |
| `门+N` | 正数门 | 增加鹅数量 |
| `门-N` | 负数门 | 减少鹅数量 |
| `火锁` | 火元素门 | 火元素 |
| `雷锁` | 雷元素门 | 雷元素 |
| `冰锁` | 冰元素门 | 冰元素 |
| `弓箱` | 弓武器架 | 弓 |
| `杖箱` | 法杖武器架 | 法杖 |

`左` 列导入为 `lane = -1`，`右` 列导入为 `lane = 1`。空白单元格和 `空` 不生成事件。无法识别的词条会在 Unity Console 中给出警告，并跳过该词条。

## 当前运行时注意事项

当前游戏代码会把正数 `G` 事件生成成鹅笼，因此 `门+N` 的 `N` 暂时不会按正数门结算。这是原有运行逻辑的问题，不是导入器或 Excel 字段映射问题；负数门、元素门、武器架和鸡群按表导入。
