# 关卡表导入说明

项目保留两份独立的 Excel 源表，**不要合并**：

- `model.xlsx`：角色、Buff、怪物数值。Unity 菜单 `Tools > Demo > Import Model Table` 写入 `Assets/Resources/Config/model_config.json`。
- `关卡表.xlsx`：关卡空间轴摆放（教学关 1–5 的源表）。运行时读的是 `Assets/Resources/Config/level_config.json`。

游戏启动时优先读导入的 JSON；文件不存在、为空或格式无效时，才用 `GooseMergeDemoBootstrap.BuildLevels()` 里的内置关卡。

## 当前生效的关卡源表（三路 + Y）

`关卡表.xlsx` 的 `Sheet1` 格式：

| 列 | 含义 |
| --- | --- |
| `id` | 关卡编号。每关从 y=1 写到 y=43，中间空一行分隔 |
| `y` | 逻辑高度。**y 越小越先碰到**。开局按 y 一次性刷完，物体往玩家落 |
| `x1` / `x2` / `x3` | 左 / 中 / 右，对应 `lane = -1 / 0 / 1` |

第 2 行是车道标记：`x1=-1, x2=0, x3=1`。

时间换算：`y = 13 + 秒`。教学关 30 秒 → 占用 y=13…43。JSON 里 `time` 全为 `0`，位置只看 `y`。

同一格可用 `+` 叠多种东西，例如 `鸡6+大公鸡`。门前挡子弹的鸡写在 **比门小 1 的 y**（先碰到鸡，再碰到门）。

生成脚本：`tools/build_teaching_levels.py`。改教学时间轴后重跑，会同时写 `关卡表.xlsx` 和 `level_config.json`。旧 Demo 四关备份在 `关卡表_备份_20260919.xlsx`。

`Tools > Demo > Import Level Table` 仍是旧的两路时间轴导入器（`source` 表 + `关卡/左/右/秒`），**不能直接吃本表**。

## 词条映射（教学文档 → 关卡表 → JSON）

| 教学文档 | 关卡表单元格 | JSON | 说明 |
| --- | --- | --- | --- |
| `空` | 空白 | 不生成 | |
| `笼+N` | `鹅笼/血N/N` | kind 4 GooseCage | 走进去固定 +N；health 与 count 均为 N |
| `倍-N` / `倍+N` | `门-N` / `门N` | kind 0 Gate | 倍增门。开枪让数字 +1，走进去按当前数加人/减人 |
| `弓架` | `武器架/弓箭/H` | kind 2, weapon=1 | H 为血。第 2 关第一只 H=5，路中间保底 H=2 |
| `杖架` | `武器架/法杖/H` | kind 2, weapon=2 | H=6 |
| `火锁` | `火门/H` | kind 1, element=1 | 第 3 关 H=3；第 5 关主选择 H=4，补门 H=2 |
| `电锁` | `雷门/H` | kind 1, element=2 | 同上 |
| `母鸡n` | `鸡` / `鸡n` | kind 3, chicken=0 | 普通鸡，actor 4 |
| `大公鸡n` | `大公鸡` / `大公鸡n` | kind 3, chicken=1 Fat | actor 5 长矛鸡 |
| `小鸡n` | `小鸡` / `小鸡n` | kind 3, chicken=2 Fast | actor 6 剑盾鸡 |
| `坤坤` | `坤坤` | kind 3, chicken=3 Boss | 第 5 关 y=40（约 27s） |

鸡种受 `GooseMergeDemoBootstrap.ChickenActorId` 限制：母鸡=4，大公鸡=5，小鸡与坤坤都走 6。美术未拆开前，手感差靠数量和元素克制区分。

## 教学关约束（第 1–5 关）

每关 30 秒、6×5 秒、三路。开局 1 只鹅、弹弓、无元素。

| 关 | 出题 | 解题 | 不要放 |
| --- | --- | --- | --- |
| 1 | 母鸡鸡群 | 鸡笼 + 倍增门（左右顺序相反） | 武器架、元素门、大公鸡、小鸡、坤坤 |
| 2 | 更密母鸡 | 弓架、杖架 | 元素门、大公鸡、小鸡、坤坤 |
| 3 | 大公鸡 | 只给 1 扇火门 | 电门、小鸡、坤坤 |
| 4 | 小鸡仔 | 只给 1 扇电门 | 火门、坤坤 |
| 5 | 混合鸡群 | 先一种元素再另一种 → 激光 | 冰门；进关不给激光；坤坤只在 27s |

膨胀段倍增门用红门大负数起手（第 1 关 `-20/-16/-32`，第 2 关 `-42/-36/-58`，第 3/4 关约 `-50/-75`）。每枪数字只 +1；弓/杖段人多，绿门几秒就会打飞。第 5 关激光不打门，膨胀门只做浅负 `-12/-18/-28`。门前必须有怪挡子弹。

## 旧两路时间轴导入器（保留，不用于当前 5 关）

`Tools > Demo > Import Level Table` 仍要求 `source` 表和 `关卡、左、右、秒` 四列。旧词条：`鸡N` / `肥鸡` / `快鸡` / `鸡boss` / `门±N` / `火锁` / `雷锁` / `冰锁` / `弓箱` / `杖箱`。该路径没有中路，也没有 `y` / `health` / kind 4 鹅笼。
