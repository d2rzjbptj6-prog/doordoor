# 第1关：两路样例验证

以下代码可以直接替换 `GooseMergeDemoBootstrap.cs` 中 `BuildLevels()` 的第1关定义。时间区间按起始秒转换，左路使用 `-1`，右路使用 `1`。

```csharp
mLevels.Add(Level("第1关：两路样例验证", "来自关卡source_两路_第1关样例.xlsx。",
    C(1f, -1, ChickenKind.Normal, 2), C(1f, 1, ChickenKind.Normal, 2),
    G(3f, -1, 4), G(3f, 1, 8),
    C(6f, -1, ChickenKind.Normal, 2), C(6f, 1, ChickenKind.Normal, 2),
    G(8f, -1, -12), G(8f, 1, 6),
    G(11f, -1, 8), G(11f, 1, 8),
    C(12f, -1, ChickenKind.Normal, 3), C(12f, 1, ChickenKind.Normal, 3),
    G(13f, -1, -20), G(13f, 1, -20),
    C(16f, -1, ChickenKind.Normal, 3), C(16f, 1, ChickenKind.Normal, 3),
    G(17f, -1, 8), G(17f, 1, 8),
    C(18f, -1, ChickenKind.Normal, 6), C(18f, 1, ChickenKind.Normal, 6),
    C(24f, -1, ChickenKind.Normal, 5), C(24f, 1, ChickenKind.Normal, 5)));
```

## 表格写法

| 表格内容 | 代码写法 |
| --- | --- |
| `鸡2` | `C(time, lane, ChickenKind.Normal, 2)` |
| `鸡3` | `C(time, lane, ChickenKind.Normal, 3)` |
| `鸡5` | `C(time, lane, ChickenKind.Normal, 5)` |
| `鸡6` | `C(time, lane, ChickenKind.Normal, 6)` |
| `门+8` | `G(time, lane, 8)` |
| `门-12` | `G(time, lane, -12)` |
| 左路 | `lane = -1` |
| 右路 | `lane = 1` |
| `3-5` 秒 | 取 `3f` |

注意：当前项目里正数 `G` 事件仍会生成固定 `+3` 鹅笼，只有负数门会按减人数门处理。这个片段只是把表格转换成当前代码的事件格式，没有修改门逻辑。
